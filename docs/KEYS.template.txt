================================================================
 HOW TO USE THESE WHEN REBUILDING THE CATALOG
================================================================

Create a file called  .env.local  in the project root
(it is git-ignored — see .gitignore, the line ".env*"):

    TMDB_API_KEY=<paste here>
    NEXT_PUBLIC_SUPABASE_URL=https://otgniwtpnxnyiqtrctqg.supabase.co
    NEXT_PUBLIC_SUPABASE_ANON_KEY=<paste here>
    SUPABASE_URL=https://otgniwtpnxnyiqtrctqg.supabase.co
    SUPABASE_SERVICE_ROLE_KEY=<paste here>

Or pass one inline, which leaves nothing on disk at all:

    TMDB_API_KEY=xxxx npm run catalog

================================================================
 IF A KEY EVER LEAKS
================================================================
TMDB       : Settings -> API -> regenerate. Old key dies instantly.
Supabase   : Project Settings -> API -> "Reset service role key".
             Then check Logs for anything you did not do.
Anthropic  : console.anthropic.com -> API Keys -> delete, create new.
             Check Usage for spend you did not make.
GitHub     : github.com/settings/tokens -> revoke.

Deleting a leaked value out of a file is NOT enough — git keeps
every old version forever, and on a public repo it was already
copied by scanning bots within minutes. Always rotate the key
itself, never just edit the file.
