# Decisions

Why the project is the way it is. These do not expire when the catalog is
rebuilt, because they are arguments rather than measurements.

A decision here should say: what was chosen, what was rejected, and what would
have to become true for the decision to be revisited. If it contains a number,
that number belongs in `docs/experiments/` with a commit and a catalog size
stamped on it, and should be linked rather than copied.

| | |
|---|---|
| Facts about right now | `CURRENT.md` — generated, never edited |
| Arguments | here |
| Measurements | `docs/experiments/` — dated and stamped |
| Superseded documents | `docs/archive/` — under a banner |
